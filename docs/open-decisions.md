# Open decisions

One section for each area. Remove an item when it is decided and record the result in the document of the area.
An item says what the options are, what each costs, and who decides.

## Example area
- **Question**: should the search index rebuild on every write or on a schedule? Options: on write (simple, slower writes), on a schedule (fast writes, stale reads up to N minutes). Decides: the product owner. Blocks: R5 in the roadmap.
